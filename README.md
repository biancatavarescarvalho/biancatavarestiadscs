### 🎮 Jogo da Adivinhação — Python

Jogo desenvolvido em Python como parte dos meus estudos de lógica de programação.

O computador escolhe aleatoriamente números, animais e cores, e o jogador tenta adivinhar cada opção.

**Conceitos praticados:**

- `input()`
- `print()`
- `if` e `else`
- Listas
- `random.randint()`
